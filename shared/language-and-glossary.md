# Language Guide and Glossary

## How to talk to Brand GMs and successors

- Reply in the language the user writes in. If they mix languages, reply mainly in their first language and keep common business terms in English (P&L, SSSG, labour %).
- Tone: polite and warm, professional, not stiff. Short sentences. One question at a time. Use bullet lists for options.
- Explain an abbreviation the first time it appears in a conversation.
- Numbers: use the brand's currency and the user's date conventions; thousands separators; mark figures from memory as approximate.
- Never correct the GM's language; structure their meaning.
- Item bodies are written in the contributor's language. If the team works in two languages, add `title_alt` and a one-line summary in the second language so search works in both.

## Glossary

| Term | Meaning |
|---|---|
| Brand GM (General Manager) | Owns one brand end to end, including its P&L |
| Area manager | Runs several stores through their store managers |
| P&L (profit and loss) | Sales, costs and profit statement |
| SSSG (same-store sales growth) | Sales growth of stores open in both periods |
| Traffic / bills / transactions | Number of guest checks |
| Average check | Sales ÷ bills |
| Food cost % / labour cost % | Cost of goods / staff cost as a share of sales |
| Prime cost | Food + labour |
| Occupancy | Rent and site costs |
| EBITDA | Earnings before interest, tax, depreciation and amortisation |
| Capex (capital expenditure) | Investment in new stores or refurbishments |
| Payback / break-even | Time to recover the investment / sales level where profit is zero |
| QSC (quality, service, cleanliness) | Core operating standards |
| SOP (standard operating procedure) | Written way of doing a task |
| Peak hour / day / date | Busiest hours, weekdays, and calendar dates (holidays, events) |
| Sold out (86) | Item no longer available |
| Roster / split shift | Staff schedule / one person working two periods in a day |
| LTO (limited time offer) | Menu item or promotion for a limited period |
| Menu engineering | Classifying items by popularity and margin (stars, plowhorses, puzzles, dogs) |
| Uplift / incremental sales | Extra sales caused by an action, measured against a control |
| Cannibalisation | New sales that come at the expense of existing ones |
| Aggregator | Third-party delivery platform |
| Own channel | The brand's own app, website, loyalty programme |
| DC (distribution centre) / central kitchen | Shared warehouse / shared production kitchen |
| Franchisor / brand owner | Owner of a licensed brand and its standards |
| Succession plan / successor / readiness | Plan for who takes over a role / that person / how ready they are |
| Knowledge card / item | One reusable piece of the GM's know-how |
| Decision pattern | How the GM diagnoses and decides a type of problem |
| Reasoning example | The GM thinking a real case through, step by step, in their words |
| Red line | A locked rule the coach never advises breaking |
| Shadow GM | The coach predicts the GM's decision; the GM corrects it |
| Flag / retro | A user marks an answer as not right / the GM reviews flagged answers |
